# hermes-stagehands

> **Sovereign & Stagehands** — A delegation provider plugin for [Hermes Agent](https://github.com/NousResearch/hermes-agent).

Routes background tasks to typed, budgeted backstage worker models (`scout`, `librarian`, `code_monkey`, `adversary`, `briefer`) while the primary agent stays pure, warm, and sovereign.

Built for the **Hermes Agent Plugin Hackathon (Nov 2026)** by Tyler Gray (@Peetborg) & Nimbo.
